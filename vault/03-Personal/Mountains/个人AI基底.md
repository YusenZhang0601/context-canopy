# 个人AI基底

## 核心摘要

本山脉卡片演示 Second Brain Climb（爬山模型）的核心实践，不代表任何使用者的当前进展。使用者必须确认山顶、当前位置、差距与下一信息行动后，才能把示例改成个人山脉事实。

## 爬山模型要素

1. **山顶定义 (Summit)**：实现完全不依赖任何特定 AI 厂商、完全由本地 Markdown 驱动的跨 Agent 终身个人知识基底。
2. **当前高度 (Current Height)**：此公开种子包含标准 Vault 治理体系、MCP 事务服务器、7 个 Second Brain Skills 与独立的 `capture-knowledge` Skill；尚未证明使用者已完成宿主接入。
3. **关键差距 (Gaps)**：需要进一步适配更多终端 Agent 宿主（如 Cursor, Hermes, Local Ollama 等）。
4. **下一信息行动 (Next Information Action)**：收集社区对单 Prompt Bootstrap 流程的跨平台反馈并优化错误处理。
